# SkyRing Mobile (React Native / Expo) ✈️🗺️

Мобильное приложение дневника путешествий SkyRing на **React Native + Expo**.

---

## 📱 Возможности в мобильной версии:
1. **Интерактивная карта мира**:
   - Полноценный зум двумя пальцами (Pinch-to-zoom) с точной фиксацией фокуса.
   - Плавное панорамирование одним пальцем.
   - Добавление и удаление посещённых стран в одно касание.
   - Поиск городов и стран (геокодинг).
   - Точки посещённых городов.
2. **Вращающийся 3D-глобус**:
   - Вращение пальцем и просмотр своих отметок на земном шаре.
3. **Воспоминания о поездках**:
   - Заметки, даты, выбор транспорта (самолёт, поезд, автомобиль и т.д.).
4. **Лента историй сообщества**:
   - Публикация поездок, лайки, впечатления.
5. **Профиль путешественника**:
   - Статистика посещённых стран, процент открытого мира, список мест.
6. **Авторизация**:
   - Вход и регистрация через Firebase Auth.
7. **Поддержка языков**:
   - Быстрое переключение интерфейса (RU / EN).

---

## 🚀 Как запустить на телефоне:

### 1. Перейдите в папку mobile:
```bash
cd mobile
```

### 2. Установите зависимости:
```bash
npm install
```

### 3. Запустите проект через Expo:
```bash
npx expo start
```

### 4. Откройте на телефоне:
- Установите приложение **Expo Go** из App Store (iOS) или Google Play (Android).
- Отсканируйте QR-код из терминала камерой телефона (iOS) или через Expo Go (Android).
- Приложение мгновенно запустится на вашем смартфоне!
